# 岛上的 AI（ai-on-island）

把**文字或文本类文件**拖到 WinIsland / WinLand 灵动岛上，AI 立刻读懂内容并给出 4~6 条可点即用的处理建议；
也可以直接点开面板自己写需求。所有请求都发往**你自己配置的 OpenAI 兼容接口**，不经过任何中间服务器。

## 能做什么

拖一份内容上去 → 弹出处理面板。面板是**三步走**的，同一时刻只显示一步，不把东西全摊在一屏：

### ① 选做法

- 顶部一行「来源」：`拖入的文字 · 42 字`，右边一个「看全文」——**默认收起**，卡片一打开先让你看到"能做什么"
- 下面就是 **AI 建议卡片**：模型读完你拖进去的内容后，**针对这份内容**给出贴合主题的动作
  - 上行短标题、下行灰字是**完整指令**（鼠标悬停看全文），点一下就用它发给模型
  - 文字 → 摘要、润色、翻译、**转换成 JSON / YAML / 表格**、提取待办、拟回复…
  - 每条建议都带具体参数（例如「转换成 JSON，字段：title, author, date」），不是空泛的动词
- 底部一行「**自己写需求**」→ 进第②步

### ② 写需求

整屏只干一件事：写要求。上面仍提醒你内容是什么，下面一个多行输入框，
`Ctrl + Enter` 或点「开始处理」提交。

### ③ 看结果

标题栏显示这次用的指令，中间是**流式**输出（可随时「停止」），底部是状态行 + 「复制结果」。
左上角「换个做法」回到第①步，之前的建议还在。

步骤之间切换有轻微的淡入上移过场。

> 面板上的建议标题会写明**这份建议是谁给的**：默认是「AI 建议 · 点一下直接执行」；
> 如果没调用 AI（关掉了自动生成、或调用失败/返回格式不对），标题会明确写成
> 「通用动作（未调用 AI）」之类，不会被误当成模型敷衍。

> 没配置 API 时，第①步整屏换成一段引导文字，告诉你去哪儿填。

## 怎么用

1. 打开 WinIsland **设置 → 插件 → 岛上的 AI**
2. 填三项：
   - **API 地址**：填到 `/v1` 就行，例如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1`
   - **API Key**
   - **模型名**：例如 `gpt-4o-mini`、`deepseek-chat`
3. 点「**测试连接**」确认通了
4. 把东西拖到岛上，选「**问 AI**」或「**AI 读文件**」卡片松手

支持的拖入内容（**只收这两种**）：

| 来源 | 说明 |
|------|------|
| 浏览器/编辑器里选中的文字或链接 | 走「问 AI」卡片，直接作为文本处理 |
| 资源管理器里的文本类文件 | 走「AI 读文件」卡片：`.txt .md .json .csv .log .xml .yaml .svg` 以及常见源码扩展名（`.cs .py .js .sql …`） |

图片、二进制文件、文件夹**不会**出现投放卡片 —— 这是宿主按卡片声明的类型与扩展名自动过滤的，不需要你手动避开。

> 一次拖多个文件时只处理第一个，面板会提示同批还有几个。

## 可选设置

| 设置项 | 说明 |
|--------|------|
| 随机性 temperature | 0 = 稳定可复现，1 = 更发散 |
| 单次最多输出 token | 0 表示不限制 |
| 追加的风格要求 | 会被拼到系统提示词后面，例如「回答一律用中文，代码块带语言标记」 |
| **思考模式** | **默认关闭**。开启后模型先推理再回答，更准但明显更慢。**一个开关管全部调用**（生成建议 + 执行 + 测试连接）。旁边必须选「字段名」—— 各家服务商没有统一标准：DeepSeek / 智谱用 `thinking`，OpenRouter / o 系列用 `reasoning`，通义千问用 `enable_thinking`，Ollama 用 `think`，不认识这个字段的服务商（OpenAI 官方等）选「不发送」。**关闭时也会按这个字段发一次 disabled** —— 见下面「为什么关掉思考还要选字段名」。 |
| 在灵动岛上显示 | 关掉后插件继续运行，只是不占岛 |
| 拖入后自动让 AI 想建议 | 默认开。关掉则省一次请求，只给一组**标注为「未调用 AI」**的通用动作 |

### 速度

生成建议那一步是"冷启动"里最慢的一环（要等服务端把一整段 JSON 吐完）。为此做了三件事：

1. **提示词压短** —— 建议指令从约 700 字压到约 330 字，条数从 4~6 条降到 3~4 条，输出量几乎减半
2. **送进去的内容截断** —— 生成建议时只贴前 1800 字（原来 4000 字），模型只要看懂"这是什么"就够了
3. **思考模式默认真的关掉了** —— 见下面「为什么关掉思考还要选字段名」。这条其实是三件事里最关键的

真正耗时的还是模型本身。想更快可以换小模型、或把 temperature 调低。

### 为什么关掉思考还要选字段名

因为**有些服务商的 API 默认就开思考**。实测 `deepseek-flash`：

| 请求体里写了什么 | 服务端实际行为 |
|---|---|
| **什么都不写**（"关闭"的直觉做法） | ❌ 照样思考，返回里带 `reasoning_content` |
| `"thinking":{"type":"disabled"}` | ✅ 真的不思考 |
| `"thinking":{"type":"enabled"}` | 思考 |
| `"reasoning":{"enabled":false}` | ❌ 不认这个字段，照样思考 |

所以本插件在**关闭**时也会按你选的字段名主动发一次 `disabled`；只有选「不发送这个字段」
才真的什么都不加（给不认识该字段的服务商，比如 OpenAI 官方 —— 乱发陌生字段会被 400）。

思考过程（`reasoning_content`）插件**不读取也不显示** —— 那些 token 你既看不到、又要为它等，纯亏。

## 实现要点

- 只依赖 `System.Text.Json` + `HttpClient`，**没有第三方依赖**，插件包很小
- 用到三块增量 API，`min_host_version` = **`2.3.1`**：聚光卡（2.1）、文件投放（2.2）、主题适配（2.3）；抬到 2.3.1 的原因见下
- 形态动画逐帧直接赋值（不用 Storyboard）；配色跟随岛体明暗
- 所有网络请求走 `SemaphoreSlim` 排队串行化，不会静默丢弃并发请求；开始新操作会取消上一次
- **界面只用框架类型**（`Grid` / `StackPanel` / `ScrollViewer` / `Button` / `TextBlock`），
  插件里**不注册 `DependencyProperty`**：插件程序集是动态加载的，不在宿主的 XAML 元数据里，
  DP 注册会让 XAML 属性系统解析不到 owner 类型而触发**原生 fail-fast**（`0xc000027b` + `E_POINTER`），
  宿主的 `Application.UnhandledException` 拦不住，会直接崩掉整个 WinIsland 进程。
  v1.0.0 就栽在这里（自写的 `WrapPanel`），1.0.1 已改为 `ScrollViewer` + 竖向 `StackPanel` 行列表。
  初始化过程分四步打点记日志，出问题看 `plugin.ai-on-island.log` 就能定位到哪一步。

### ⚠️ 为什么要求宿主 2.3.1

宿主 2.3.0 及更早版本有一个 bug：插件注册投放目标时，宿主的守卫复制**漏掉了 `Kinds` 字段**，
导致所有插件卡片在运行时都被当成「只收文件」。后果就是本插件的「问 AI」卡片会去接任意文件，
而**真正的文字投放完全无效**（卡片根本不出现）。

该 bug 已由宿主在 **Core 2.3.1** 用 `record` + `with` 整体复制修掉。所以本插件的
`min_host_version` 定为 `2.3.1` —— 宁可装不上，也不让用户装上一个"拖文字没反应"的版本。

### 想恢复「拖入图片让 AI 看图」

读取与请求侧的图片支持（vision 消息、`ImageBytes`）都还在，只是投放卡片不再收图片。恢复只要两处：

1. `AiOnIslandPlugin.RegisterDropTargets` 里 `ask-ai` 的 `Kinds` 改成
   `IslandDropKind.Text | IslandDropKind.Image`
2. 同一处 `ask-ai-file` 的 `Extensions` 追加 `.png .jpg .jpeg .gif .bmp .webp`

（模型还得支持看图：`gpt-4o`、`qwen-vl-max`、`glm-4v` 等。）

## 隐私

API Key 存在 WinIsland 的插件设置里（本机），请求直接从你的电脑发往你填的那个地址。
插件不做任何遥测，也不会把 Key 写进日志。
